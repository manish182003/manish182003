</div>

> From raw environmental audio to an explainable deep-learning prediction.

### 🎵 End-to-End Pipeline

```text
🎵 Raw Audio
      │
      ▼
📊 Mel Spectrogram
      │
      ▼
🧠 ResNet-34 Style CNN
      │
      ▼
🎯 50 Environmental Sound Classes
      │
      ▼
🚀 FastAPI + Modal
      │
      ▼
🌐 React Visualization
```

### 🧠 Model

- Custom **ResNet-34-style 2D CNN**
- **21M+ parameters**
- **50 environmental sound classes**
- PyTorch
- torchaudio
- Mel-spectrogram input

### 🛡️ Regularization

To address overfitting on a small training dataset:

- SpecAugment
- Mixup
- Label smoothing

### ⚙️ Training

```text
Optimizer       → AdamW
Scheduler       → OneCycleLR
Training        → 100 epochs
GPU             → NVIDIA T4
Framework       → PyTorch
```

### 🌐 Deployment

The model is deployed through a **serverless FastAPI endpoint on Modal** with a React frontend for:

- Audio waveform visualization
- Predictions
- CNN activation maps
- Explainable model output
